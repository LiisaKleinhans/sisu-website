# Sisu website

Static website for Sisu (growwithsisu.com). No build step: Vercel serves the files as they are.

- `index.html` Home
- `about.html` About Me
- `services.html` Services (the service cards are filled in from `js/services.js`)
- `contact.html` Contact
- `css/style.css` Colours, fonts and layout
- `images/` Logo, portrait and favicon
